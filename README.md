# Manga World NPC Portraits

《漫画世界模拟器 / 绝不想变成BL！》的可扩展随机 NPC 立绘目录。

## 使用方式

- 角色卡只读取根目录的 `catalog.json`。
- 图片地址由 `catalog.json` 所在 URL 加各资源的相对 `path` 得到。
- 存档只保存稳定的 `portraitGroupId` 与 `portraitAssetKey`，不保存完整图片 URL。
- `character-*` 是无固定姓名、无固定剧情身份的外观组，不是预设角色名单。
- 新增人物时追加新的 group、asset 和文件；已经发布的 group ID 与 assetKey 不改名、不删除。

## 当前目录

- 21 个外观组。
- 70 张 PNG。
- 分类维度包括成年少年感/青年感、发型、发色、瞳色与外观特征。
- “少年感”只表示成年人物的外貌气质，不表示未成年。

## 内容提示

目录包含成人向男性人物图片。请仅在适合的环境中查看和使用。
